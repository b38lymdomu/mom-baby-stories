# 漂流的尽头是骨科？炎炎夏日水上运动火爆，记得做好这些事

> 更新时间：2026-09-17 (UTC+8)

这个夏天

所有人的感受都是

热~死~了！

在如此炎热的夏季

水上运动成了大家的最爱

毕竟，这天气

除了玩水

户外还能玩啥？

在所有玩水项目中

今年漂流特别火热

小编的朋友圈几乎每个周末

都能刷到许多好友去漂流

漂流看着不需要技术含量

但其中却也隐含着不少风险

千万不要让漂流的尽头去骨科……

 

 

**年轻妈妈为保护孩子**

**突然……**

“医生，我前天去漂流扭了一下，怎么就没办法走路了。”这天一大早，浙江大学医学院附属第一医院总部一期骨科门诊，蔡友治副主任医师刚坐下没多久，就有一位打扮时髦的女士被轮椅推着进了诊室。

 

陈女士（化名）是位85后妈妈，有个刚上二年级的儿子，平时她就很喜欢带着孩子去户外爬山、露营，这段时间杭州持续高温，“憋在”家里的陈女士就研究了一圈杭州附近的漂流场所，最终选了一处漂流景区，在周末和丈夫兴冲冲地带着儿子就去玩了。

  //  

青山绿水间，漂流确实给人带来非常大的快乐和凉爽，然而，在漂流过程中，正上二年级的儿子有些害怕，想要站起来，陈女士赶紧微微站起身子想要去拉住儿子，漂流船在水中剧烈晃动，由于重心不稳，陈女士的右侧膝盖严重扭了一下，顿时一股钻心的疼痛袭来。

陈女士咬牙完成漂流，赶紧回了家。“膝盖一直红肿，但我想想应该就是扭伤，养两天就好了。”陈女士在家休息了两天，右膝盖一直疼痛难忍，甚至无法下地走路了，这下她觉得不对劲，赶紧来到了浙大一院骨科门诊。

蔡友治副主任医师为陈女士仔细检查后，**发现她右膝盖的前交叉韧带撕裂严重**。前交叉韧带是我们膝关节位置的主要韧带之一，主要作用是保障我们膝关节能稳定地前屈和旋转，**它的撕裂主要是因为膝关节突然扭转或暴力拉伸超过其强度导致**。漂流船在水流的作用下摇摆摇晃，如果这时候膝关节突然剧烈扭转，就非常容易出现这样的伤害。

由于陈女士韧带撕裂较严重，随后她在浙大一院骨科接受了关节镜微创修复手术，当天就可以下地走路。

 

**漂流时注意这些**

**保护好自己**

就在陈女士就诊后不久，蔡友治副主任医师又接诊到一位杭州的高三毕业生小李（化名）。结束高考的他，兴奋地和同学们约了一起省内游，也玩了漂流。

然而，漂流船发生了侧翻，小李撞到了石块上，身上多处受伤，**特别是膝盖重重地撞到突出的石块**，被救上岸后，小李就发现自己无法行走，朋友连忙联系他家人，父母赶来把他接回了杭州，送到浙大一院骨科，经过检查，**小李双侧膝盖的内侧副韧带撕裂**，由于撕裂不是特别严重，就进行了保守治疗。小李也只能郁闷地提早结束了暑期游。

最近这段时间，浙大一院骨科门诊里，多了不少像陈女士、小李这样因漂流造成伤害前来就诊的患者。在这个冬季，我们曾做过一篇科普《雪场的尽头是骨科？》，而到了夏季，我们却发现，似乎漂流的尽头，也变成了骨科。

浙大一院骨科主任胡懿郃教授表示，虽然相比滑雪，漂流并不需要个人太大的运动参与，你只要坐在皮艇上，顺流而下，就可以享受清凉的刺激。然而，看似不需要运动的漂流，其实也隐含了许多危险因素。

首先，皮艇在水中还是有一定的侧翻危险，虽然漂流的河水一般不会太深，但游客一定要穿好救生衣。漂流的地方往往是顺流而下，河道不会太宽敞，两旁多有乱石，这时候人就很容易碰伤，有些漂流景区为游客配备了头盔，**建议参加漂流，尤其是刺激性比较强、落差比较大的漂流，要佩戴头盔、护膝，做好保护作用**。

其次，皮艇在水流作用下，非常摇晃不稳，而踩下去又不像陆地那么平稳，一旦起身很容易跌倒，而且很容易扭伤膝盖，专家建议：**在漂流时一定要坐稳，扶稳把手不松手，如果万不得已要变化姿势，重心要低，适度下蹲，不可以完全站起身**。

另外，目前大部分漂流景区对孩子的身高或年龄有限制，大家千万一定要遵守景区的规定，漂流这项运动还是具有一定的刺激性，太小的孩子可能会害怕，会乱动，这就会造成非常大的安全隐患，李女士正是因为想要照顾孩子，才导致了受伤。专家建议，**如果带着孩子玩漂流，一定要提前和孩子做好沟通**，可以给他们看一些漂流的视频，如果孩子不愿意，不要强求，避免发生危险。

 

**水上运动快乐**

**但也要注意安全**

炎炎夏日，玩水是大家最喜欢的事情，也几乎成为唯一的户外运动选择。然而，水火无情，一方面，溺水事故还是时有发生，大家在户外玩水时特别是游泳、水上乐园玩耍时，一定要注意安全，尤其是对孩子，父母千万不能让孩子离开自己的视线。

另一方面，近几年溯溪、漂流等带有野外运动性质的水上运动越来越火爆，但这些运动还是需要参与者具备一定的身体条件和野外知识，建议大家选择正规的机构参加活动，同时做好防护、安全措施，在运动中要听从领队、专业者的要求。**一旦发生伤害，建议尽快送医，避免延误病情。**
